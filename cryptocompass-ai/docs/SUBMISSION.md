# Binance Agent OS Mini Hackathon — Submission Pack

## Track
Track A — Build an AI Agent with Binance Agent OS.

## Project
CryptoCompass AI by ELCRYPTOBOY

## One-liner
Research before you trade: a beginner-first AI crypto research agent that combines Binance market context, explainable technical signals and risk guardrails.

## Demo flow
1. Open the live demo.
2. Show live Binance market snapshot for BTC, ETH, BNB, SOL, XRP and DOGE.
3. Ask: “¿Cómo interpretar la tendencia de BTC antes de tomar una decisión?”
4. Run the research agent and show observed data, trend, momentum, risks and next checks.
5. Open `.mcp.json` and `AGENTS.md` to show Agent OS / MCP configuration.

## Architecture
User → Binance market data → analysis engine → research workflow → evidence/risk explanation → human review.

## Safety
No order execution is enabled in the hosted MVP. Future execution should require least-privilege permissions and explicit human approval.
